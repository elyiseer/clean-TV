# Xiaomi Mi TV (MiTV-MOOQ1, codename tarzan), Android TV 10 (SDK 29), firmware QTG3.200305.006.6148
# Same model as examples/xiaomi-mi-tv-4a (firmware ...2591). This list is for the newer build and
# only names packages that are actually installed here (checked against `pm list packages -f`).
# It follows examples/xiaomi-mitv-mooq0, which is the same chassis family and was lived with.
#
# STATUS: draft. Not yet lived with for a few days on this TV. Replace this line with what you
# tested and what broke before opening a pull request (see CONTRIBUTING.md).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mooq1/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mooq1/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
# Apply in small batches (split the file) and reboot once between them.
#
# Kept deliberately, despite names that look like bloat (same findings as MOOQ0, `dumpsys package`):
#   com.xiaomi.android.tvsetup.partnercustomizer  Bluetooth remote pairing (BleRcActivity)
#   com.mediatek.hotkey.dispatcher                the remote's hotkey service, including Source
#   com.mediatek.tvinput                          serves HDMI, composite AV and the tuner
#   com.mediatek.wwtv.setupwizard                 channel tuning wizard for Live TV
#   com.mediatek.wwtv.tvcenter                    Live TV; its activity is also the HDMI/AV window,
#                                                 hide it in the launcher (hidden_apps) instead
#   mitv.service, com.xiaomi.mitv.res             core TV service and framework resources
#   com.xiaomi.mitv.updateservice                 Xiaomi firmware updates: the only source of
#                                                 system security patches, so it stays enabled
#   com.google.android.katniss                    voice assistant (mic button)
#   com.google.android.apps.mediashell            Chromecast built-in
#   com.google.android.tv.remote.service          phone-as-remote
#   com.google.android.gms, com.android.vending, com.google.android.webview
#                                                 Play Services, Play Store, WebView: these keep
#                                                 the streaming apps and their security patches
#                                                 updating through the Play Store
#
# Home claimants on this firmware: the stock launcher is com.google.android.tvlauncher (an updated
# /data app, priority 2). com.duokan.factorytest below also declares HOME at priority 0.
# NOTE: com.google.android.tvlauncher is deliberately NOT in this list. launcher/build-and-install.sh
# disables it only after the replacement launcher is installed and verified as Home.
# Run the launcher install BEFORE anything that touches Home, never after.
#
# Known quirk on the older ...2591 build: default_input_method pointed at com.baidu.input, which is
# not installed, so no keyboard appeared in search fields. Gboard is installed here. Check with
#   tools/tv.py 'settings get secure default_input_method'
# and, if it is not Gboard, set it (README Troubleshooting, "No on-screen keyboard").
#
# Sideloaded apps (Kodi, VLC, SmartTube, ...) and eu.chainfire.tv.sideloadlauncher are not listed
# on purpose: they are the owner's own apps.
